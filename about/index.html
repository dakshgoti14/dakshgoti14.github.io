How I work

How I think about engineering

Four principles, each paired with a decision from one of my projects.

  1. 01Scalability

    Design systems that keep performing as traffic, users, and data volumes grow.

    OrderStream moves orders between services on fault-tolerant Kafka streams, processing 200K+ a day.

    OrderStream case study

  2. 02Reliability

    Build with failure handling and operational readiness in mind.

    ContextFlow retries every agent call with exponential backoff and persists each step, so a transient model error doesn’t fail the document.

    ContextFlow case study

  3. 03Performance

    Measure first, then optimize the path that matters.

    VectorForgeDB ships a benchmark harness; in its README run, HNSW answers in ~4ms P95 versus ~120ms for exact search.

    VectorForgeDB case study

  4. 04Product thinking

    Build around real user problems, not technology for its own sake.

    ContextFlow flags low-confidence extractions for human review instead of silently trusting the model.

    ContextFlow case study
